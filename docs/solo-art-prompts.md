# 솔로 추리게임 — 장면/초상 일러스트 가이드 (하이브리드)

지금은 모든 장면·초상이 **벡터(SVG)로 자동 렌더**됩니다(무료·오프라인). 실제 그림을
아래 경로에 넣으면 **자동으로 그 그림이 우선 표시**되고, 없으면 SVG로 폴백합니다.
파일만 넣으면 되고 코드 수정은 필요 없습니다.

## 드롭인 경로
| 대상 | 넣을 위치 | 권장 규격 |
|---|---|---|
| 방/시설 장면 배경 | `public/images/scenes/<장소ID>.jpg` | 가로 16:9, 1600×960 이상, jpg |
| 인물 초상 | `public/images/people/<파일명>` (아래 표) | 정사각, 512×512, png/jpg |

> 장면은 `<장소ID>.jpg`가 기본이며, 다른 파일명을 쓰려면 `src/solo/soloContent.js`의 해당 장소에 `image: '/images/...'`를 지정하세요.

## 공통 스타일(프롬프트에 붙이면 통일감↑)
```
어두운 느와르 범죄 추리물 일러스트, 차분하고 탁한 색감, 약간의 그레인,
평면적/회화적 벡터 스타일, 사람 없음(장면), 부드러운 실내 조명, 16:9, 몰입감 있는 분위기
```
