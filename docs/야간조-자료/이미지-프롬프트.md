# 「야간조」 단서 사진 — 생성 프롬프트

> 카드 109장 중 **실사 사진이 필요한 것은 63장**. 나머지는 폰·태블릿 화면 UI, 카메라 통행 기록 HTML, 평면도 SVG 다.
> 저장 위치는 `public/images/yaganjo/` 이고 **파일명은 데이터팩(`src/data/yaganjo/`)의 `image` 값 그대로**다.
>
> **진행 — 9 / 63 완료.** A·B 아홉 장을 실제로 뽑았고, 그 과정에서 얻은 처방이 이 문서의 1장이다.

> 2026-09-17, Gemini(Flash)에서 아홉 장을 실제로 뽑아 얻은 것이다. 열네 번 생성해서 아홉 장을 건졌고,
> 초반 다섯 장에 아홉 번을 쓴 뒤 처방이 서고 나서는 네 장에 네 번으로 떨어졌다.
> **이 문서의 규칙은 추측이 아니라 실패 다섯 건에서 나온 것이다.**

## 0. 한 줄 요약

**「글자를 없애라」가 아니라 「한글로 채우되 초점을 빗나가게」다.**

---

## 1. 실패 다섯 — 무엇이 안 되는지부터

| | 무엇을 시켰나 | 무슨 일이 났나 |
|---|---|---|
| **1** | 「**경찰** 감식 증거 사진」 | 「경찰」이 **피사체로 옮아갔다.** 물류센터 순찰 일지가 「경찰 파트롤 로그」가 됐다 |
| **2** | 「글자는 초점 밖으로 흐리게」 | 약했다. 제목이 또렷하게 찍히고 **한글이 깨졌다** |
| **3** | 「인쇄된 제목·로고·영문이 하나도 없는 **빈 양식지**」 | 손글씨와 서명까지 같이 지워졌다. 표가 통째로 비어 「결재란 첫 칸에만 서명」이라는 급소가 사라졌다. **그런데 영문 라벨은 그대로 들어왔다** |
| **4** | 「**영어나 로마자는 단 한 글자도** 안 된다」 | **키릴 문자로 갔다.** 러시아어 공문이 나왔다. 양식 서류엔 뭔가 적혀 있어야 한다고 모델이 강하게 믿어서, 금지하면 금지 안 된 문자를 찾아간다 |
| **5** | 「위쪽에 굵은 **제목 한 줄**이 있고 가운데 **항목 칸**만 파란 볼펜 손글씨로」 | **그 설명문이 종이에 그대로 인쇄됐다.** 종이에 「굵은 제목 한 줄, 인쇄 양식 서류」·「파란 볼펜 손글씨」가 찍혀 나왔다 |

**그래서 셋을 지킨다 — ① 「경찰」을 쓰지 않는다 ② 구조를 설명하지 않고 문서 이름을 준다 ③ 글자를 빼지 말고 한글로 채우되 초점을 빗나가게 한다.**

---

## 2. 톤 두 갈래 — 베이스

**⒜ 증거 촬영대** (사물함 · 소지품 · 현장 물증 · 서류)
```
증거 촬영대에서 찍은 감식 사진: 짙은 회색 무광 촬영대 위에 <피사체> ; 비스듬히 내려찍기, 단일 하드 스포트라이트, 깊은 그림자, 옆에 숫자 증거 표식 하나 ; 사람 없음 ; 실사 사진, 일러스트·CG 금지 ; 1:1 정사각
```
서류는 「비스듬히」 대신 **「정면에서 살짝 기울여 내려찍기」**.

**⒝ 현장** (통로 · 휴게실 · 충전소 · 탈의실 같은 공간)
```
<공간>을 찍은 감식 사진: 천장 형광등 백색광 아래 회색 콘크리트 바닥, 정면에서 한 걸음 물러나 찍기 ; <피사체> ; 사람 없음 ; 실사 사진, 일러스트·CG 금지 ; 16:9
```

## 3. 글자 꼬리 — 종이·라벨이 나오는 모든 장에 반드시 붙인다

```
; 종이 위의 문자는 한글 뿐이고 영어나 로마자는 없으며 카메라 초점이 종이 면에서 크게 빗나가 있어 어느 낱말도 판독되지 않는다
```

**서명이 있는 장에는 한 줄 더:**
```
; 서명은 이름이 아니라 흘려 쓴 획으로만 보인다
```
→ 서명 이름이 읽히면 안 된다. 실제로 「지우영」·「신주영」이 또렷하게 찍혀 나온 적이 있고, 그 각서는 차민우와 박태식 것이라 다른 이름이 보이면 판이 헷갈린다.

**얼굴이 들어갈 수 있는 장(사원증·학생증·신분증):**
```
; 사진 자리는 스포트라이트 반사로 하얗게 날아가 아무것도 보이지 않는다 ; 사람 없음, 얼굴 없음
```

## 4. 문서 이름을 직접 준다 — 구조를 설명하지 않는다

「위쪽에 굵은 제목 한 줄이 있고 가운데 항목 칸만…」이라고 쓰면 **그 말이 종이에 인쇄된다.**
대신 **한국 서류의 실제 이름**을 준다 — 「합의 각서」 · 「사고 조사 보고서」 · 「야간 순찰 점검표」 · 「복약 안내문」 · 「시험 시간표」 · 「심야조 명부」 …
그러면 그 이름이 제목으로 또렷하게 찍히고 나머지는 흐려진다. **그게 맞는 그림이다** — 카드 앞면이 이미 값을 들고 있으므로 사진은 「무슨 서류인지」만 말하면 된다.

## 5. 안전 필터 — 아이 사진은 거부된다

A4에서 **「미성년자를 그런 식으로 묘사하는 이미지는 생성할 수 없습니다」**로 거부당했다. 원인은 「담요에 싸인 아기 사진」이다.

**우회 둘:**
- **소품을 바꾼다** — 아기 사진 대신 아주 작은 면양말 한 켤레. 뜻은 그대로 서고 필터에 안 걸린다
- **뒷면만 찍는다** — 「인화지 뒷면이 위로 오게 뒤집혀 있고 뒷면에 볼펜으로 날짜가 적혀 있다」.
  야간조에서는 이쪽이 **오히려 설정에 맞다** — D4·X4는 「사진 뒷면의 생년월일」이 폰 잠금의 출처이므로 뒷면이 요점이다

→ **아이·아기·딸 사진이 들어가는 장은 전부 「뒷면만」으로 바꾼다.**

## 6. 조작 수칙

1. **프롬프트는 한 줄.** 개행이 들어가면 문단마다 전송돼 쪼개진다. 구분은 세미콜론과 하이픈
2. **전송은 ↑ 버튼 클릭.** Enter는 한글 IME와 충돌한다
3. **새 방의 첫 프롬프트는 공백을 눈으로 확인**한다. 첫 입력이 한글 사이 공백을 날리는 일이 잦다
4. **한 세션에 6~8장, 갈래를 섞지 않는다.** ⒜와 ⒝를 섞으면 3~4장째부터 배경이 옮아간다
5. **재시도 기준 셋** — 얼굴이 들어왔다 / 한글이 깨져서 또렷하다 / 일러스트 느낌이 난다
6. 받은 파일은 `public/images/yaganjo/`에 **데이터팩의 `image` 값 그대로**(ASCII 케밥) 저장. 1:1은 1024×1024, 16:9는 1600×900, jpeg 품질 80

8. **X3 세 장의 초점을 각각 다른 데 맞췄다** — ⓐ는 수첩 전체, ⓑ는 **찢긴 밑동에만** 초점(글씨 면은 빗나감), ⓒ는 글자는 못 읽되 **필압·잉크 차이만 또렷하게**.
