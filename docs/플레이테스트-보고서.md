# 새벽이슬 크라임씬 · solo 모드 플레이테스트 최종 보고서

## 1) 총평 — 처음 하는 사람이 겪을 가장 큰 문제 세 가지

첫째, **심문이 앉아서 탭만 하는 구간이 된다.** 전체 추정 탭의 70%가 심문 화면이고(934/1,335탭), 화제 하나를 열 때마다 예외 없이 3탭이 들고(32개 전부 press 보유 = 96탭), 캐묻기를 마치면 방금 읽은 답변이 처음부터 다시 타이핑되면서 ▶조차 사라진다. 같은 단서를 4~6명에게 되풀이해 들이대게 되어 있고(화제 속 단서 줄 111개 중 41개가 중복), 20ms/자 고정 타이핑에 스킵도 속도 설정도 없다. 둘째, **폰 세로에서 단서를 찾지도 누르지도 못한다.** 375px 화면에는 방 그림의 21%만 보이는데 핫스팟 63개 중 37개(59%)가 초기 화면 밖이고, 방 '안'에는 4초짜리 스와이프 힌트 한 번 외에 아무 안내가 없다. 27%는 44px 터치 최소 크기 미달이며, 은재방 운동화 흙은 하단 대사창에 완전히 가려 사실상 획득이 불가능하고, 획득 ✓ 표시는 hover 전용이라 폰에서는 영영 안 보인다(그나마 그 CSS 규칙은 선택자가 틀려 데스크톱에서도 죽어 있다). 셋째, **심문의 논리가 플레이어의 신뢰를 잃는다.** 수사관의 추궁 대사가 용의자 이름표로 출력되고, 짚지도 않은 증거(다이어리·영수증·목사 폰)를 근거로 단정하며, 사랑은 방문을 자백하는데 게임은 인정하지 않고, 반대로 현지 다이어리 하나로 2차 반전인 자매 관계가 1차에 통째로 새어 나간다. 여기에 확인 창 없는 「사건 파일 제출」과 📓 바로 옆의 운영자 패널이 겹쳐, 오탭 한 번으로 수사가 끝나거나 단서가 영구 소실될 수 있다.

## 2) 결함 목록

> 심각도 기준: **blocker** = 진행 불가 또는 되돌릴 수 없는 손실 / **major** = 짜증·오해가 큼 / **minor** = 다듬으면 좋음.
> 코드상 '영구 진행 불능' 하드락은 발견되지 않았다(2막 진입에 필요한 목사방 단서 3개는 초기 화면 안에서 확보 가능). 아래 blocker 2건은 **되돌릴 수 없는 손실** 기준이다.

## 5) 확인 못 한 것 / 실제 플레이로 봐야 할 항목

- **실제 손가락 정확도.** 44px 미달 17개와 poly clip-path의 조합, 사랑방 책더미 오탭 빈도, 목사방 약통 오탭을 플레이어가 알아채는지 — 전부 정적 계산이라 실기 확인 필요.
- **GYPV-39가 정말 못 눌리는지.** 최대 하단 팬 상태에서 대사창 실제 높이(3줄 가정)를 실측해야 한다. 대사창 길이에 따라 슬리버가 생길 수도 있다.
