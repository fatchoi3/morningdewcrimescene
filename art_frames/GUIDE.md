# 눈 깜빡임 프레임 만들기 — 무료 인페인트 웹툴 (당신 생성 · 나머지는 코드가)

목표: 원본에서 **눈만 감기고 나머지는 100% 원본 그대로**인 이미지 1장.
이게 되면 코드가 눈 부위만 잘라 깜빡임을 붙인다.

## 왜 "인페인트(부분 편집)"여야 하나
- ChatGPT/Gemini 채팅에 "다시 그려줘" = **전체 재생성 → 정렬 깨짐**(테스트로 확인, 못 씀).
- Firefly 생성형 채우기 = 정렬은 되지만 **유료**(액세스 막힘).
- ✅ **무료 SD 인페인트 웹툴** = 브러시로 칠한 부분만 다시 그리고 나머지는 원본 유지 → 정렬 OK, 무료.

## 무료 도구 (하나 골라서)
1. **getimg.ai** → 상단 "Tools" 또는 "AI Editor/Edit image" → **Inpainting(인페인트)**. 무료 크레딧 제공.
2. **playground.com** → 로그인 → 이미지 업로드 → **Edit → Mask/Inpaint(브러시)**. 무료 티어.
3. **leonardo.ai** → Canvas Editor → 업로드 → 브러시 마스크 + 프롬프트. 무료 티어.
(셋 다 "브러시로 칠한 영역만 프롬프트대로 다시 그림" 방식)

## 공통 순서

2. **브러시로 "두 눈"만** 칠하기 (눈썹·코 말고 눈 부위만. 조금 넉넉히 덮어도 됨)

## ⭐ 반드시 확인 (이게 핵심)
다운로드한 이미지가 **눈 빼고는 원본과 똑같아야** 합니다.
- 얼굴 각도·머리·옷·몸·손·크기·위치가 그대로 → ✅ 성공(인페인트 제대로 됨)
- 뭔가 전체적으로 달라졌다 → ❌ 전체 재생성된 것. 그 도구의 "부분/브러시 편집" 모드가 맞는지 다시 확인.
